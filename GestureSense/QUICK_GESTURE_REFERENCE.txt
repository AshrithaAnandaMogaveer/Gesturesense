WHAT CAN YOU SHOW?
------------------
The system recognizes 114 ISL WORDS (not alphabet letters).
These are full word gestures from Indian Sign Language.


EASIEST GESTURES TO START WITH:
--------------------------------

1. I_ME_MINE_MY        → Point to yourself (chest)
2. YOU                 → Point forward (at camera/person)
3. FOOD                → Hand to mouth (eating motion)
4. WATER               → Cupped hand to mouth (drinking)
5. HELLO_HI            → Open palm wave / flat hand forward
6. THANK               → Hand from chin/lips moving forward
7. HELP                → One hand on other palm (supporting)
8. SORRY               → Fist circling on chest
9. GOOD                → Positive gesture (like thumbs up position)
10. STOP               → Flat hand raised (stop sign)

WHAT IS NOT RECOGNIZED:
-----------------------
❌ Alphabet letters (A, B, C, D, etc.)
❌ Numbers (1, 2, 3, 4, etc.)
❌ Generic gestures (Thumbs up, Peace, OK sign)
❌ Random hand shapes


HOW TO SEE THE EXACT GESTURES:
-------------------------------
Look at the training images in your project:

📁 ISL_CSLRT_Corpus/ISL_CSLRT_Corpus/Frames_Word_Level/

Each folder (e.g., "HELLO_HI", "FOOD", "THANK") contains example photos

TIPS FOR GOOD RECOGNITION:
---------------------------
✓ Good lighting
✓ Hand clearly visible in frame
✓ Hold gesture steady for 0.3-0.5 seconds
✓ Not too close, not too far (arm's length)
✓ Match the actual ISL gesture from training images


UNDERSTANDING THE OUTPUT:
-------------------------
The system shows:
- Gesture name (e.g., "HELLO_HI", "FOOD", "THANK")
- Confidence % (e.g., 68%, 45%, 32%)

Confidence guide:
>60% = Very confident (accurate)
40-60% = Confident (good)
30-40% = Uncertain (maybe)
<30% = Very uncertain
